What it does它能做什么

PolishPop lives in the menu bar. It reads only the text you deliberately select, rewrites it, and shows you the result before touching anything. PolishPop 常驻菜单栏。它只读取你主动选中的文字,润色之后先给你看结果,再决定要不要替换。

±

See every change改动一目了然

A word-level diff highlights what was added and removed — character by character for Chinese, which has no spaces between words. 逐词高亮增删内容;中文没有词间空格,所以按字高亮。

✎

Six use cases, five tones六种用途,五种语气

Email, chat message, social post, business update, announcement, or let it infer the format. Professional, natural, friendly, concise or executive. 邮件、即时消息、朋友圈、工作汇报、通知公告,或让它自动识别格式。语气可选专业、自然、亲切、精简、决断。

Replaces in place原地替换

The draft goes back into the field you selected it from. If the app will not accept a direct write, PolishPop pastes it and restores your previous clipboard. 润色结果写回你选中它的那个输入框。若该应用不接受直接写入,则临时用粘贴方式替换,随后恢复你原本的剪贴板。

Installing安装步骤

This build is not notarized by Apple, so macOS will not open it until you say so explicitly. Every route below ends with you extending that trust — what differs is how much you can check first. 这个版本没有经过 Apple 公证,所以 macOS 在你明确表态之前不会打开它。下面每条路径最终都需要你授予这份信任,区别只在于你事先能核实多少。

Terminal终端安装 verifiable可核验

Downloads the archive, checks it against the published SHA-256, and installs it. Files fetched with curl are never marked as quarantined, so macOS shows no block dialog at all. PolishPop already needs the Codex CLI installed through npm, so you have a terminal open anyway. 下载安装包、比对已公布的 SHA-256、然后安装。用 curl 取回的文件不会被打上隔离标记,所以 macOS 完全不会弹出拦截对话框。反正 PolishPop 本来就要用 npm 装 Codex CLI,终端你已经开着了。 

cd /tmp \
  && curl -fsSLO https://polishpop.eric-c85.workers.dev/PolishPop-0.5.0.zip \
  && shasum -a 256 -c <<< "5066409faa20a603fe899b3b6ca32ddb723e39c87b8d3616e4826b8f7f1fd23f  PolishPop-0.5.0.zip" \
  && unzip -oq PolishPop-0.5.0.zip -d /Applications \
  && open /Applications/PolishPop.app

If the checksum does not match, the chain stops and nothing is installed. 校验和对不上时,整条命令会中断,不会安装任何东西。

Why any of this is necessary为什么要这么麻烦

Apple notarizes software only for members of its Developer Program. PolishPop is signed — with a certificate issued on the developer's own machine, which keeps your Accessibility permission working across updates — but it has never been submitted to Apple, so Gatekeeper cannot vouch for it and says so. Notarization is the only thing that removes these steps, and it is on the roadmap rather than done. Apple 只为其开发者计划的成员提供公证服务。PolishPop 是有签名的——使用开发者本机签发的证书,好让你的辅助功能授权在版本更新后依然有效——但它从未提交给 Apple,所以 Gatekeeper 无法为它背书,也就如实提示。只有公证能免掉上述步骤,而那还在计划中,尚未完成。

Privacy隐私

Text leaves your Mac only when you ask for a rewrite — never while you are simply selecting or typing. 只有你主动要求润色时,文字才会离开你的电脑——只是选中或打字时不会。

  • What is sent发送什么 Only the selection, and only after you click the sparkle button or press the shortcut. 仅发送你选中的那段文字,且仅在你点击闪光按钮或按下快捷键之后。
  • Where it goes发送到哪 To OpenAI through the official Codex app server, in a fresh throwaway session each time, with transcript history disabled. 经由官方 Codex 服务发送给 OpenAI,每次都是全新的一次性会话,且已关闭记录留存。
  • What is stored保存什么 Nothing. PolishPop keeps the last result in memory for five minutes so you can copy it again, then drops it. 不保存。最近一次结果仅在内存中保留五分钟供你再次复制,之后即丢弃。
  • What is refused拒绝读取 Password fields and DRM-protected content are never read. 密码输入框和受 DRM 保护的内容,一律不读取。

Your ChatGPT plan's own data controls, retention rules and usage limits still apply. Do not select passwords, banking details, private keys or confidential records. 你的 ChatGPT 套餐自身的数据控制、留存规则与用量限制依然适用。请勿选中密码、银行信息、私钥或机密资料。
